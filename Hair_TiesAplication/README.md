Aplicação no http localhost visando refinar o uso de SQL em conjunto com Python e aplicar isso na prática de projetos completos.

O usário deve colocar seu cadastro (podendo ou não usar uma senha) e em seguida realizar um pedido com base no banco de dados já criado em sql.

A parte em html deve ser estudada e auxiliada pelo projeto usando Model-View-Controller, do curso do GitHub sobre Padrões de Projeto.
